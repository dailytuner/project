## 🌟 О проекте

**Psychometry Service v4.0** — это микросервис, который помогает человеку осознать своё текущее состояние и принять осмысленное решение. В отличие от классических астрологических сервисов, которые отвечают на вопрос *«Что будет?»*, мы отвечаем на вопрос *«Что со мной сейчас?»* и *«Что делать?»*.

Проект построен на стыке:
- **Астрологии** (эфемериды, транзиты, биоритмы, финансовые индикаторы)
- **Психометрии** (опросники, T-scores, индексы состояния)
- **Философии осознанности** (практика «Пауза», наблюдение, выбор)

Мы не предсказываем будущее — мы помогаем его создавать.

## 🎯 Зачем это нужно

### Проблема

Существующие астрологические сервисы дают:
- ❌ Общие прогнозы («Сатурн в 8 доме»)
- ❌ Пассивное чтение («Что будет со мной?»)
- ❌ Отсутствие обратной связи
- ❌ Разрыв между «знанием» и «действием»
- ❌ **Одна ось** вместо многомерного подхода

### Решение

Psychometry v4.0 предлагает:
- ✅ Персонализированное состояние (энергия, тревога, эмоции)
- ✅ Конкретные рекомендации («Выделите 15 минут на тишину»)
- ✅ Интерактивную практику («Пауза» с таймером 15 секунд)
- ✅ Сбор обратной связи для обучения системы
- ✅ Интеграцию с астрологическим контекстом (биоритмы, транзиты)
- ✅ **5 категорий жизни** вместо 1 оси 🆕
- ✅ **Прогноз окна возможностей на 7 дней** 🆕
- ✅ **Финансовые индикаторы из астрологии** 🆕

## ✨ Ключевые особенности

### 1. 5 категорий жизни вместо 1 оси 🆕

Вместо абстрактной «судьбы» мы работаем с конкретными сферами жизни:

| Категория | Что оцениваем | Пример рекомендации |
|-----------|---------------|-------------------|
| 👨‍👩‍👧‍👦 **Семья** | Отношения, связь с близкими | «Запланируйте вечерний разговор» |
| 💼 **Работа** | Карьера, задачи, проекты | «Начните новый проект» |
| ❤️ **Здоровье** | Физическое состояние, энергия | «Сходите на прогулку» |
| 🧘 **Self** | Саморазвитие, творчество | «Запишите свои идеи» |
| 💰 **Деньги/Достаток** 🆕 | Финансы, доход, инвестиции | «Отличное время для инвестиций» |

**Почему «Деньги» — отдельная категория?**
- Финансы — одна из главных тем в астрологических запросах
- Астрологические индикаторы (2 дом, Юпитер, Венера) дают конкретные сигналы
- Психометрические шкалы (Ma, Pa) связаны с финансовым поведением
- Пользователи хотят конкретных рекомендаций по деньгам, а не абстрактных прогнозов

### 2. Прогноз окна возможностей 🆕

Теперь пользователь может видеть не только текущее состояние, но и **прогноз на 7 дней вперёд**:

```
📈 Прогноз окна на 7 дней

┌─────┬──────────┬────────────┬──────────────┐
│ День│   Значение│    Уровень │      Тренд   │
├─────┼──────────┼────────────┼──────────────┤
│ 01.09│   0.72   │    OPEN    │    📈 rising │
│ 02.09│   0.58   │   PARTIAL  │    📉 falling│
│ 03.09│   0.45   │   PARTIAL  │    ➡️ stable │
│ 04.09│   0.38   │   CLOSED   │    📉 falling│
│ 05.09│   0.52   │   PARTIAL  │    📈 rising │
│ 06.09│   0.65   │   PARTIAL  │    📈 rising │
│ 07.09│   0.78   │    OPEN    │    📈 rising │
└─────┴──────────┴────────────┴──────────────┘

📌 Лучшие дни для действий: 01.09, 07.09
📌 Дни для наблюдения: 04.09
```

**Как это работает:**
1. Берём текущее состояние пользователя (энергия, тревога, эмоции)
2. Получаем астро-контекст на каждый день вперёд (биоритмы, транзиты, сезонные бусты)
3. Рассчитываем окно для каждого дня
4. Показываем тренд и рекомендации

### 3. Интерактивная практика «Пауза»

Пользователь может в любой момент:
1. Нажать кнопку «Пауза»
2. Заметить автоматическую мысль
3. Записать её в поле ввода
4. Получить подтверждение осознанности

Это превращает пассивное потребление контента в активную практику.

### 4. Индексы с сезонными бустами и астрологическими индикаторами

Индексы достижения учитывают не только состояние пользователя, но и:
- **Биоритмы** (физический, эмоциональный, интеллектуальный циклы)
- **Транзиты** (сила планет в данный момент)
- **Сезонные бусты** (время года влияет на разные сферы)
- **Финансовые индикаторы** (2 дом, Юпитер, Венера) 🆕

Формула индекса для категории «Деньги»:

```
Индекс = Ясность × 0.35 + Синхронность × 0.35 + Ресурс × 0.30
Буст = Сезонный_буст × 0.20 + Астрологический_фактор × 0.15
Итог = Индекс × (1 + Буст) - Инерция × 0.10
```

Астрологический фактор для денег учитывает:
- Силу Юпитера (планета изобилия)
- Силу Венеры (планета финансовых возможностей)
- Силу 2 дома (дом денег и ресурсов)

### 5. Обучение через обратную связь

Каждая рекомендация может быть оценена пользователем:
- ⭐ Рейтинг 1-5
- 📊 Исход (помогло/не помогло)
- 💬 Комментарий

После накопления 500+ оценок система калибруется.

## 🚀 В чём новизна

### 1. Астрология → Осознанность

**Традиционный подход:**
> «Сатурн в 8 доме — ждите трансформации»

**Наш подход:**
> «Ваше окно в работе закрыто — отложите решения и понаблюдайте»

Мы переводим астрологический язык на язык действий.

### 2. Пассивное → Интерактивное

**Традиционный подход:**
> Пользователь читает прогноз → закрывает вкладку

**Наш подход:**
> Пользователь видит состояние → получает рекомендацию → выполняет практику «Пауза» → оценивает результат

Мы создаём цикл осознанного управления.

### 3. Универсальное → Персональное

**Традиционный подход:**
> Один прогноз для всех пользователей

**Наш подход:**
> 3 метрики + 5 индексов + 5 рекомендаций + прогноз на 7 дней = **более 20 персональных точек внимания**

Каждый пользователь получает уникальный набор данных.

### 4. Линейное → Многомерное

**Традиционный подход:**
> Одна шкала (судьба)

**Наш подход:**
> 5 категорий + окно возможностей + прогноз + осознанность = **8 измерений**

Мы показываем не только «как дела», но и «что с этим делать».

### 5. Статичное → Обучаемое

**Традиционный подход:**
> Система не меняется

**Наш подход:**
> Каждая оценка улучшает систему → после 500+ feedback — калибровка

Система становится умнее с каждым пользователем.

### 6. Текущее → Будущее 🆕

**Традиционный подход:**
> Только «здесь и сейчас»

**Наш подход:**
> Текущее состояние + **прогноз на 7 дней вперёд**

Пользователь может планировать свои действия, опираясь на прогноз.

3. **Психометрическое:** Шкалы Ma и Pa напрямую связаны с финансовым поведением.
4. **Практическое:** Финансы — одна из самых частых тем в запросах пользователей.
5. **Ценностное:** Конкретные рекомендации по деньгам ценнее абстрактных прогнозов.

## 📈 Прогноз окна возможностей

### Как это работает

```
Текущее состояние → Прогноз на 7 дней
        ↓                    ↓
   Энергия 0.72         День 1: 0.72 (OPEN)
   Тревога 0.38         День 2: 0.58 (PARTIAL)
   Эмоции 0.55          День 3: 0.45 (PARTIAL)
                        День 4: 0.38 (CLOSED)
                        День 5: 0.52 (PARTIAL)
                        День 6: 0.65 (PARTIAL)
                        День 7: 0.78 (OPEN)
```

### Для чего это нужно

| Сценарий | Польза |
|----------|--------|
| **Планирование** | Знать лучшие дни для важных решений |
| **Подготовка** | Знать дни, когда лучше наблюдать |
| **Осознанность** | Видеть тренд, а не только текущую точку |
| **Мотивация** | Видеть, что состояние может улучшиться |

### Пример использования

> Пользователь видит, что в пятницу окно будет закрыто, а в понедельник — открыто. Он откладывает важное решение на понедельник, а в пятницу занимается рутиной и наблюдением.

## 🌿 Философия

Проект построен на модели **«Наблюдатель → Субъект → Фон»**:

```
Наблюдатель → Субъект → Фон
     ↓           ↓          ↓
   Цель      Состояние   Контекст
     ↓           ↓          ↓
   Осознание → Действие → Результат
```

**6 шагов практики осознанности:**

1. **СХВАТЫВАНИЕ** — заметить импульс
2. **ПАУЗА** — остановиться на 15 секунд
3. **РАСПОЗНАВАНИЕ** — отличить факт от интерпретации
4. **ВЫБОР** — принять решение
5. **ЗАПЕЧАТЛЕНИЕ** — запомнить новое
6. **ИНТЕГРАЦИЯ** — применить в жизнь

**Наш девиз:**
> *«Не предсказывать будущее, а помогать осознать настоящее и принять решение»*

### Ключевые решения

| Решение | Обоснование |
|---------|-------------|
| **Отдельный микросервис** | Не ломаем существующую логику Astro Service |
| **Redis как общий кэш** | Используется и Astro, и Psychometry |
| **Circuit Breaker** | Защита от каскадных отказов при недоступности Astro |
| **Idempotency Keys** | Защита от дублирования запросов |
| **Batch с пагинацией** | Масштабирование при росте пользователей |
| **Floor 0.05 для окна** | Философское решение — всегда есть пространство для наблюдения |
| **5 категорий жизни** | Более полное покрытие сфер жизни 🆕 |
| **Прогноз на 7 дней** | Возможность планирования 🆕 |
| **Финансовые индикаторы** | Астрологическое обоснование категории «Деньги» 🆕 |
